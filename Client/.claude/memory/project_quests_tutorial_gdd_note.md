2026-10-15 при создании ГДД квестов (`/workspace/client/.claude/docs/game-design/quests-gdd.md`) пользователь
решил задания туториала туда не вносить и оставить их для ГДД туториала. По коду: пока идёт туториал, задания
«Уничтожь 1…5 танков» выдаются по очереди, награда 1 схема танка, за пятое задание 50, таймера нет, при
обновлении задания не заменяются. Правило «после туториала обычные задания открываются сразу, без кулдауна»
(из ТЗ достижений, Правки №2) было в quests-gdd.md#gdd-tutorial; раздел удалён 2026-10-19 (решение
пользователя после merge amnesia/fix, туториал в коде сведён к остаткам).

**Why:** у туториала нет ГДД, а описание туториальных заданий относится к нему.
**How to apply:** при создании ГДД туториала предложить внести эти задания как в коде (с подтверждением) и
уточнить у пользователя, нужен ли он вообще (раздел туториала в ГДД квестов удалён 2026-10-19). Связано: [[server-quests-deferred-fixes]], [[server-tutorial-deferred-fixes]].
