# Правило: язык ответов — русский для всех агентов, не только основного ассистента

Пользователь явно попросил закрепить, что правило "все ответы на русском" (из
`CLAUDE.md`) распространяется НЕ ТОЛЬКО на основной диалог, но и на ЛЮБЫХ
агентов/субагентов, запускаемых через Agent tool — встроенных (Explore,
general-purpose, Plan) и кастомных (`.claude/agents/<команда>/*.md`, например
[[db-persistence-agent]] если такая память будет создана).

**Почему**: правило было только неявным (общая фраза "ответы ассистента
пользователю" в `CLAUDE.md`), пользователь захотел явной гарантии при
появлении первого кастомного агента (`db-persistence`).

**Как применять**:
1. В `/workspace/client/CLAUDE.md` и `/workspace/server/CLAUDE.md` в разделе
   "Язык общения" добавлена явная фраза про агентов/субагентов.
2. При создании НОВОГО кастомного агента (`.claude/agents/<команда>/*.md`) — включать в
   его системный промпт отдельную строку "Отвечать пользователю только на
   русском" (уже сделано для `server-developer-db-persistence`, файл
   `/workspace/server/.claude/agents/developers/server-developer-db-persistence.md`).
3. При делегировании задачи встроенному агенту (Explore/general-purpose/Plan)
   через Agent tool — если его финальный отчёт увидит пользователь напрямую,
   явно указывать в prompt агента, что ответ должен быть на русском (не
   рассчитывать только на CLAUDE.md, если есть сомнение, что он подхватится).
