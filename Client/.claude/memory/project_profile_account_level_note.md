2026-10-15 при дополнении ГДД поезда по ТЗ «Механика кора» пользователь решил: уровень игрока — область профиля,
в train-gdd.md не фиксировать. Что известно:
- по ТЗ уровень аккаунта качается призывами поезда по таблице (Google-таблица, лист gid=1177181592); прогресс
  показан рядом с аватаркой; анимация повышения — партикли и золотой текст «Новый уровень»;
- по коду: +1 опыта игроку за призыв танка в поезде и за призыв на аэродроме, предмет коллекции опыта не даёт;
  таблица UserLevel, 100 уровней; анимация LevelUpAnimation в Header, текст global.levelUp;
- от уровня игрока зависит уровень выпавшего танка (±5) — это правило уже в train-gdd.md#gdd-tank-roll.

**Why:** ГДД профиля нет, а уровень игрока к поезду относится только как источник опыта.
**How to apply:** при создании ГДД профиля (или задаче по уровню игрока) предложить внести это, спросить про
опыт за аэродром (в ТЗ только поезд) и сослаться на train-gdd.md#gdd-tank-roll.
