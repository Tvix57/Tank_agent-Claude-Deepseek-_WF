# Область ответственности

Слой Cocos и ассеты экрана базы:

- `Last_shift/assets/scripts/game/ui/BaseScreenView.ts` — плитки этажей, карточка комнаты, выбор;
- `game/ui/UiPrefabs.ts`, `ui/AtlasSprite.ts`, `ui/UiKit.ts`, `ui/Names.ts`, `ui/Layout.ts`;
- префабы `assets/resources/prefabs/Base.prefab`, `RoomTile.prefab`, `RoomCard.prefab`,
  `HudChip.prefab`, `BlueprintSlot.prefab`;
- генератор `Last_shift/tools/build_ui_assets.py` — источник геометрии префабов;
- атлас `assets/resources/atlas/base-ui` — иконки `icon_<id>` 52×52 (D-020).

Механика комнат — не твоя область, это `room-analyst`.

# На что обращать внимание

- Экраны 1–3 комнат на этаж, 11 плиток: порядок слева направо — часть интерфейса, перестановка без
  записи в `DECISIONS.md` не делается.
- Карточка комнаты: что видно без открытия — адрес, состояние, прогресс, цена, эффект.
- Обратная связь по вниманию: плитка показывает, что комнате нужно внимание (ремонт, нехватка
  ресурсов), а не только цвет.
- Ввод: тап по плитке выбирает, повторный тап не запускает ремонт случайно.
- Бюджеты: draw calls ≤ 60, шапка и база не перерисовываются каждый кадр.
- Пиксели: геометрия задаётся в pt 390×844, перевод в 1284×2778 — только в `Layout.ts`.
