# Область ответственности

`Last_shift/assets/scripts/game/**` и ассеты экрана:

- `game/ui/BaseScreenView.ts`, `game/ui/UiPrefabs.ts`, `game/ui/AtlasSprite.ts`, `game/ui/UiKit.ts`,
  `game/ui/Layout.ts`, `game/ui/Names.ts`, `game/boot/GameRoot.ts`;
- `assets/resources/prefabs/*.prefab`, `assets/Scenes/Game.scene`;
- `tools/build_ui_assets.py` — генератор сцены и префабов, если меняется геометрия;
- атлас `assets/resources/atlas/base-ui` (иконки `icon_<id>` 52×52).

Не трогаешь: `core/**`, конфиги чисел, симуляцию.

# Рабочий процесс

1. Вход: архитектура или документ области, раздел про экран.
2. Состояние комнаты приходит из `core` (`BaseMap`, `RoomStatus`) — UI читает и отображает.
   Собственных правил «когда комната готова» в `game/` не появляется: это дубль правила.
3. Геометрия — в pt 390×844; перевод в пиксели только в `Layout.ts`. Новые размеры не хардкодятся
   по месту.
4. Иконки — из набора `base-ui` (`icon_<id>`), сцена в плитку не ужимается (D-020).
5. Префабы: правка руками в редакторе и правка генератора не должны расходиться — источник геометрии
   называется в саммари.
6. Проверки: `cd Last_shift && npm run typecheck`; при изменении генератора — `npm run assets`.
   Наблюдаемое поведение в Cocos проверяет Пользователь: сценарий шагами, результат фиксируется
   дословно.
7. Саммари: `СДЕЛАНО` / `ФАЙЛЫ` / `РЕШЕНИЯ` / `РИСКИ` / `ОТКРЫТО`.

# Самопроверка (`#code-risk-check`)

- В `core/` не появилось импортов из `cc` после правки.
- Плитка и карточка не перерисовываются каждый кадр без изменения состояния.
- Повторный тап по плите не запускает второе действие.
- Draw calls в бюджете (≤ 60), новые спрайты не плодят материалы.
- Текст и числа на экране берутся из данных, не из литералов в коде.
