Часть игроков не возвращается снова в веб игру, поскольку могут просто о ней забыть или потерять.

В Яндекс Играх есть механика, которая позволяет прямо внутри игры выводить игроку кнопку, по которой
его отправят в интерфейс самих ЯИ где ему предложат создать ярлык игры у себя на экране (телефон или
пк)
Эту же функцию можно вызывать и в браузере, без привязки к ЯИ.

Чтобы игроков мотивировать создавать ярлык игры для их дальнейшего возвращения, можно предлагать им
награду за создание ярлыка игры у себя на устройстве

**Инфа по механике**
- инструкция для яндекс игр — https://yandex.ru/dev/games/doc/ru/sdk/sdk-shortcut
- игра пример — https://yandex.ru/games/app/bimka-2-0-onlain-kresh-gonki-405114

## Изображение 1 (скриншот игры-примера, главный экран)

Ангар игры «Бимка 2.0» внутри Яндекс Игр. В верхнем левом ряду иконок, рядом с шестерёнкой настроек,
есть иконка подарка с красным значком «!». На неё указывает красная стрелка: это вход в предложение
ярлыка. Остальной интерфейс (валюты, Турниры, Банды, Награда за вход, Задания, Магазин, Играть) —
просто контекст игры.

## Изображение 2 (окно предложения)

Полноэкранное окно поверх игры: слева персонаж, справа иконка и подпись «Добавь игру», заголовок
«ДОБАВЬ ИГРУ К СЕБЕ НА ЭКРАН И ПОЛУЧИ НАГРАДУ», под ним награда — две валюты игры с количеством
($ 10000, вторая валюта 100). Кнопки: синяя «Добавить» и текстовая «Позже».
