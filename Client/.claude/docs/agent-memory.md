# Личная память агентов-специалистов

Одна копия на client и server. Специалист — любой агент, кроме `*-lead`. Лиды личной памяти не
имеют: они маршрутизируют, их знания — в ростерах, реестрах и WF.

Механизм — встроенный в Claude Code: `memory: local` во frontmatter агента. При каждом вызове в
системный промпт агента попадают стандартные инструкции памяти и его индекс
`.claude/agent-memory-local/<имя агента>/MEMORY.md` (в репозитории, где запущена сессия; путь
исключён из git). Отдельные файлы памяти читаются только по запросу.

Индекс оплачивается на КАЖДОМ вызове агента — отсюда лимиты ниже.

<a id="what"></a>
## Что записывать

Только то, что пригодится ЭТОМУ агенту в следующих вызовах и чего нет ни в коде, ни в документации
области, ни в общей памяти `/workspace/client/.claude/memory/`:

- **ловушка** — место, где агент уже ошибся или долго искал (настоящее расположение X, обманчивое
  имя, файл-дубль);
- **поправка** — замечание пользователя к работе именно этой роли, с причиной;
- **короткий путь** — повторяющийся запрос и где ответ на него (ссылка на раздел дока или файл кода,
  не пересказ).

Знание об области (как устроен компонент, решения по архитектуре) — в документ области через
регистрацию у `*-librarian-lead`. Правило для всех агентов проекта — в общую память через базовую
сессию. Ход текущей задачи — никуда.

<a id="limits"></a>
## Лимиты

- `MEMORY.md` — не больше 20 строк, строка — до 120 символов: `- [Название](файл.md) — когда открывать`.
- Файл памяти — до 20 строк тела; ссылка на раздел дока вместо пересказа.
- Достиг лимита — сначала объедини похожие записи и удали устаревшие, потом добавляй.

<a id="when"></a>
## Когда читать и писать

- Индекс уже в промпте. Файл памяти открывай, только если его строка относится к текущей задаче.
- Пиши один раз — в конце задачи, перед финальным ответом. Сначала `grep` по своей папке памяти:
  есть запись на эту тему — `Edit` её, а не новая.
- Нечего записать по разделу "Что записывать" — ничего не пиши.
- Запись противоречит документу области — значит, устарела одна из сторон: сообщи вызывающему в
  `ОТКРЫТО`, сам документ не правь.

<a id="new-agent"></a>
## Новый агент-специалист

Лид, создающий агента, добавляет во frontmatter `memory: local`, а в раздел "Правила" — строку:

```
- Личная память: что записывать, лимиты, когда писать — `/workspace/client/.claude/docs/agent-memory.md`.
  Прочитай перед первой записью в задаче.
```
