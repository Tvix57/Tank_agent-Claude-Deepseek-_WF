ГДД: `/workspace/client/.claude/docs/game-design/achievements-gdd.md`. Расхождения отмечены в
`/workspace/client/.claude/docs/achievements-architecture.md` (компромиссы, пометка «ГДД, отложено 2026-10-14»).
2026-10-14 пользователь решил их не чинить и ГДД под код не править:
- порядок списка (`AchievementsTypeSection.ts`, одна функция сравнения): группы качеств идут по убыванию, а
  должны по возрастанию («Обычное» сверху); внутри группы нет сортировки по прогрессу от большего к меньшему;
  блок «ждут награды» отсортирован по убыванию качества, а должен по возрастанию (#gdd-list-order);
- на карточке нет иконки класса перед названием класса (`AchievementLine.ts`, #gdd-card).

**Why:** ГДД создавался без задачи на исправление; чинить вместе с ближайшей задачей по достижениям.
**How to apply:** при задаче по клиентским достижениям напомнить и предложить починить, начиная с порядка
списка (прямое требование ТЗ). Перед исправлением сверить с актуальным кодом. Серверная пара —
[[server-achievements-deferred-fixes]].
