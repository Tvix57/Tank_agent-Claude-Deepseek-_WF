# TEMPLATE.txt — шаблон заметки DeepSeek

Копировать в `.deepseek/notes/<YYYY-MM-DD>-<тема>.md`, заполнить, файл оставить. `import` переносит
запись в `.claude/agents/.claude/agent-memory-local/<agent>/` и в её `MEMORY.md`.

```
title: <короткое название записи>
agent: <имя агента из .deepseek/agents, без .md>

## Запись
<что нужно помнить в следующих вызовах: ловушка / поправка пользователя / короткий путь.
Одна-три строки, ссылка на раздел документа вместо пересказа.>
```

Правила: одна запись — одна тема; общие правила проекта сюда не писать (это `instructions/rules.md`);
для документов и архитектуры — `.deepseek/docs/`, а не заметка.
