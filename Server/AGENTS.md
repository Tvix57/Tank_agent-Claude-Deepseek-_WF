# Без рефлексии

Не использовать рефлексию (`Class.getDeclaredField`/`setAccessible`/`Method.invoke` и т.п.) нигде в
серверном коде — ни для персистентности, ни для полиморфного конструирования по типу. Различение по
типу/маршрутизация — через обычный `enum`/`instanceof`/явный dispatch-параметр (например, `collectionId`
→ `CollectionsData.section`), а не через рефлексию.

# Баланс всегда считается верным

Данные баланса (Google-таблица → `balance.json` → `Balance`) — источник истины, а не входные данные,
которые код вправе чем-то заменить. Отсутствующий лист, отсутствующие обязательные данные в строке или
значение вне шкалы — ошибка, останавливающая импорт/сборку баланса с сообщением, где именно ошибка
(лист, id строки, поле).

Запрещено: необязательные листы (`optJSONArray` и подстановка пустого массива вместо данных), значения
по умолчанию вместо данных баланса, `try/catch` вокруг чтения баланса «чтобы сервер поднялся»,
молчаливый пропуск листа или строки при импорте. Незаполненный баланс — это дефект таблицы, он
правится Пользователем в таблице; заглушка в коде вместо данных баланса — только по явной просьбе
Пользователя.

# Без развёрнутых комментариев в коде

Правило — раздел «Без развёрнутых комментариев в коде» в `../client/CLAUDE.md`: архитектура и
рационале — в `.deepseek/docs/<тема>.md`, в коде либо совсем без комментария, либо одна строка
`// См. .deepseek/docs/<файл>.md#<якорь>`; короткие однострочные `//` с неочевидным WHY допустимы; ссылки
на доки живут до конца задачи и затем удаляются из кода области.

# Индексы MongoDB — миграция сразу

Новая Mongo-коллекция (новый `*Dao`) или новый фильтр запроса по полю без индекса — JSON-миграция
индекса (`game/src/main/resources/migrations/<timestamp_мс>_<имя>.json`) создаётся в ТОМ ЖЕ
изменении, не отдельным шагом потом. Формат, порядок и риски уникальных индексов — раздел «Индексы и
миграции» в `.deepseek/agents/developers/server-developer-db-persistence.md`.

## DEEPSEEK-ONLY: вернуть этот файл к CLAUDE.md (перед возвратом в Claude Code)

Симлинк `CLAUDE.md -> AGENTS.md` возможен только там, где `CLAUDE.md` нет (например, отдельный git
worktree). Порядок:

1. `grep -n 'DEEPSEEK-ONLY' AGENTS.md` — всё после первого маркера в `CLAUDE.md` не переносить.
2. Удалить `CLAUDE.md`-симлинк, записать `CLAUDE.md` без хвоста и без строки про `.deepseek/scripts/convert.py (версия 1.0)`.
   Потерялся исходный текст — он лежит в `.deepseek/instructions/project.md`.
3. `python3 .deepseek/scripts/convert.py drift` — `.claude` не должен упоминать `.deepseek`.
4. `git status -s CLAUDE.md .claude` — в диффе только ожидаемые правки задачи.
